# Goddessverse profile identity

- Theme: Goddess Veiled.
- Background: `#121016`; elevated surface: `#221e28`; border: `#2e2935`.
- Text: `#f2eff5`; secondary text: `#a39dad`.
- Pink: `#ff2e88`; gold: `#d4af6a`.
- Typography: Outfit for the wordmark and titles; Inter for supporting text.
- Mark: the existing gold, upturned crescent used by Goddessverse HQ.
- Tagline: Goddess's Creative Home.

The banner extends the existing HQ identity with rounded edges, a plum gradient, a light glass sheen, and restrained pink/gold accents. It is illustration inside GitHub's layout; it does not change GitHub's theme.

## Assets and editing

`assets/goddessverse-banner-source.svg` retains editable text; install Outfit and Inter when editing it. The display SVG converts lettering to vector outlines so GitHub does not depend on installed fonts. The README provides descriptive alt text and native text headings.

`assets/goddessverse-avatar.svg` is the vector source for the PNG avatar. The quick-link graphics contain only generic navigation labels. All artwork is static and self-contained: no scripts, trackers, remote fonts, or external image dependencies.

Outfit and Inter are licensed under the SIL Open Font License 1.1. The artwork uses outlined letterforms rather than distributing font files. Font project credits: [Outfit](https://github.com/Outfitio/Outfit-Fonts) and [Inter](https://github.com/rsms/inter).

Project-specific marks and third-party creator attribution remain with their respective projects. TipsyPrompt credits SpicyRae.

## Project Tracker panel

`assets/project-tracker-source.svg` is the editable text source; `assets/project-tracker.svg` is the outlined display version. The artwork is a navigation panel, not an embedded application or a task snapshot. It contains only the board name, workflow labels, and an opening affordance. The README supplies its actual link and private-access label. Both organization profiles and the HQ, Lab, and Atelier landing READMEs reuse this public-safe file.
